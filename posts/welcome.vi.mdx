## Chào mừng bạn đến với Retro Developer Blog

Đây là bài viết MDX đầu tiên của bạn. Bạn có thể soạn thảo bài viết mới bằng cách tạo các file `*.mdx` bên trong thư mục `posts`.

### Tích hợp Markdown & Mã nguồn

Bạn có thể cấu hình bài viết bằng GitHub Flavored Markdown, khối mã inline, bảng biểu, trích dẫn và các React component tùy chỉnh:

```typescript
// Ví dụ interface TypeScript
export interface BlogAuthor {
  name: string
  role: string
  skills: string[]
}

const author: BlogAuthor = {
  name: 'Developer',
  role: 'Software Architect',
  skills: ['Next.js', 'React', 'TypeScript', 'Tailwind'],
}
```

> Blog đã được cấu hình hoàn chỉnh và sẵn sàng triển khai sản xuất trên Vercel hoặc GitHub Pages.
