# Chào mừng

Đây là bài viết đầu tiên của bạn. Bạn có thể viết bài bằng tệp `*.mdx` trong thư mục `posts`.

## Viết bài theo kiểu GitHub

Bạn có thể đặt cấu trúc bài viết, code snippet, danh sách, bảng, và link.
